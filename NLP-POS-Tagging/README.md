# NLP POS Tagging Mini Project

This mini project demonstrates Part-of-Speech (POS) Tagging using Natural Language Processing (NLP) techniques in Python. The project processes input text and identifies grammatical categories such as nouns, verbs, adjectives, pronouns, and more using NLP libraries in Jupyter Notebook.

## Features
- Text preprocessing
- Tokenization
- POS tagging
- NLP implementation using Python
- Beginner-friendly implementation

## Technologies Used
- Python
- Jupyter Notebook
- NLTK

## Project Goal
The goal of this project is to understand the basics of Natural Language Processing and how POS tagging helps in analyzing sentence structure and language patterns.
